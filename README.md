## 建站 VPS 选型三问：访客在哪、跑什么站、谁来维护

### 第一问：网站主要给谁看

这一问决定机房，也决定线路，是整件事里最容易翻车的一环。

线路大致分四档，体验和价格基本同向：

- **普通国际线路**：便宜，晚高峰容易绕路、丢包，建站不推荐
- **CN2 GT**：电信精品网的中端线路，比普通国际线好，晚高峰仍可能拥堵
- **CN2 GIA**：电信精品网的高端线路，三网回程走 CN2，延迟稳定，是面向国内访客建站的首选

一句话概括：**站给国内人看，线路优先级高于配置；站给海外客户看，机房位置比线路档位更重要。**

### 第二问：跑什么站，决定要多大内存

1GB 能不能跑 WordPress？能跑，但它是底线，不是舒适线。

| 内存 | 能干什么 | 要注意什么 |
| --- | --- | --- |
| 1GB | 单个轻量 WordPress、个人博客、名片站、测试环境 | 别装重型插件，别上 WooCommerce，环境要精简 |
| 2GB | 正常 WordPress 站，插件若干、装缓存、跑后台任务 | 这是大多数人真正该起步的档位 |
| 4GB | 多站点同放、WooCommerce、数据库压力明显 | 单站用不满，属于给增长留余量 |
| 6GB 以上 | 认真做流量、跑其他服务 | 建站场景下多数人用不到 |

一个常见的误判是把预算全压在 CPU 上。WordPress 在访问量还没起来的时候，瓶颈通常在内存和 PHP 进程数，不在 CPU 核心数。2 核 2G 跑一个日访问几百 PV 的站，比 4 核 1G 顺畅得多。

### 第三问：谁来维护这台机器

这类 KVM VPS 的使用方式是自助的：给你 root 权限，系统和软件栈要自己装。硬件和网络由商家负责，Nginx、PHP、MySQL、SSL、备份策略、安全加固，都是你的事。

这会筛掉一批人。完全不想碰命令行、希望有人从头到尾帮你打理、站点一上来就要扛高并发，这三种情况都不该买自助 VPS，买了也会变成天天开工单。

## 常见问题

**Q：建站 VPS 和虚拟主机到底差在哪？**
虚拟主机是商家把环境打包好，你只管传网站文件，省事但受限；VPS 给你一台独立机器和 root，环境自己装，自由度高、同价位下扩展性更好，代价是要花时间搭。愿意花一个晚上，VPS 更值。

**Q：1GB 内存到底能不能跑 WordPress？**
能跑。前提是不装太多插件、不上 WooCommerce、环境精简。它能上路，但不一定舒服。真正务实的起点是 2GB。
